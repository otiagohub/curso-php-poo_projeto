Os arquivos estão organizados em `branches`, conforme as etapas de desenvolvimento da aplicação.

Navegue pelo menu `Branches` para acessar a versão desejada do projeto.

## Sobre o projeto Central de Suporte

O Central de Suporte é uma aplicação web didática desenvolvida em PHP. Seu objetivo é permitir o gerenciamento de chamados de suporte técnico, **simulando** uma situação comum no ambiente de trabalho de uma equipe de TI.

Ao longo das aulas, desenvolveremos a aplicação utilizando os conceitos de **Programação Orientada a Objetos (POO)**, construindo gradualmente suas funcionalidades.

### Funcionalidades

A aplicação permitirá:

- Visualizar a lista de chamados cadastrados.
- Consultar os detalhes de um chamado.
- Cadastrar novos chamados.
- Concluir chamados em aberto.

### Tecnologias e recursos

- PHP 8.5 ou superior.
- HTML e CSS.
- Armazenamento de dados em arquivo JSON.
- Composer para gerenciamento do autoload de classes.

### Como será o desenvolvimento

O projeto será construído passo a passo durante as aulas. Começaremos pela estrutura básica da aplicação e, gradualmente, implementaremos as funcionalidades e os conceitos de POO necessários para seu funcionamento.

Não é necessário ter conhecimentos prévios de todos os recursos utilizados. Cada conceito será apresentado conforme sua necessidade no desenvolvimento do projeto.
